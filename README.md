# Flowclone releases

Installers and update files for **Flowclone**, hold-to-dictate voice-to-text for macOS
(Apple silicon). This repository holds release files only; the source code is private.

## Install

Download the latest `Flowclone_<version>_aarch64.dmg` from
[Releases](https://github.com/MeetVox-AI/flowclone-releases/releases/latest), open it and drag
Flowclone to Applications. The app is signed and notarized by Apple.

## Updates

Flowclone checks `latest.json` on the latest release and installs updates by itself. Every
update package is signed; the app only installs packages signed with the Flowclone update key.
